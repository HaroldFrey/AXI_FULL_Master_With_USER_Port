## 已知局限（设计层面）

| 编号 | 局限 | 说明 |
|------|------|------|
| L-01 | W 数据顺序依赖用户 | FIFO 写入顺序必须 = start 顺序（AXI4 无 WID 约束） |
| L-02 | 读要求从机同 ID 保序 | 从机乱序返回（同 ARID 违规）不在支持范围（out-of-order 独立功能） |
| L-03 | start 无空闲槽时忽略 | 用户须遵守 ready_start 指示 |
| L-04 | 槽位数 ≤8 | 寄存器阵列面积约束 |
| L-05 | 旧 TB 层次引用失效 | `dut.axi_wr_master_inst.state` 已不存在，B 阶段适配为等 B 握手 |
| L-06 | 异常 BID（槽位非 B_WAIT） | 不握手挂起（从机违规场景，防御性处理） |
